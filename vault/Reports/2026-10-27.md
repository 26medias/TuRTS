## Steam compatibility assessment (staged)

The current native client has no obvious architectural blocker to a future Steam distribution: `Cargo.toml` defines the native client, and `src/main.rs` launches it. The project spec permits desktop distribution but leaves supported operating systems open. Launch options currently require explicit HTTP and WebSocket server URLs (`options.rs`); CI verifies Ubuntu only, with no Steam or Windows validation. Valve documents Steamworks API use as optional, while store review requires a build, review, and correct launch configuration for each advertised OS ([Steamworks API](https://partner.steamgames.com/doc/sdk/api), [store review](https://partner.steamgames.com/doc/store/review_process)).

Assessment: feasible, but not Steam-ready, and approval is not guaranteed. Future distribution work would need native builds and packaging per advertised OS, installed-app launch configuration, and a smooth server-join flow. Friends/lobbies, authentication, and Workshop require explicit integration if wanted; Steam Deck needs separate validation. This is an assessment only: no implementation or scope change is approved.
