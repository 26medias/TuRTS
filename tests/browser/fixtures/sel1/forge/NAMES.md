## Interface assets and provenance

- `assets/images/portrait_*.png` are original local Forge badges generated by
  `assets/build_portraits.py` using Python's standard library only. Run
  `python3 mods/forge/assets/build_portraits.py` from the repository root to regenerate them.
  The script uses simple vector primitives and the package's existing Forge palette; it fetches
  no external artwork.
- `assets/fonts/Roboto-Regular.ttf` and its accompanying
  `assets/fonts/Roboto-LICENSE.txt` are byte-for-byte copies of the already vendored Muster UI
  font and Debian copyright/license notice. Both copies match their source SHA-256; the notice
  identifies Roboto, Google Inc. (2015), under Apache-2.0. The upstream project license is not
  changed by this package asset copy.
- The six `assets/images/cursor_*.png` and four `assets/sounds/{select,order,error,alert}.ogg`
  files are byte-for-byte copies of the corresponding existing Muster package assets. Their
  SHA-256 values match the local Muster sources; no remote downloads or new recordings were used.
- The eight existing `assets/icon_order_*.png` entries are retained unchanged. Forge portraits,
  cursors, font, and sounds are declared in `assets/assets.ron` and consumed by the authored
  interface and unit presentations.
