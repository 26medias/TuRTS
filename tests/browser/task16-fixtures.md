# Task 16 physical fixtures

The seven rows KM1, KM2, SEL4, SLOT1, CAM2, SH1 and PER1 declare executable
`stages.task16` plans. The launcher validates physical actions, captures, fixed
clause IDs, fixture identities and package hashes before Cargo starts. A guarded
candidate cannot produce acceptance evidence. The oracle owns the checks;
caller-supplied predicates, debug paths and pixel patches are not accepted.

The driver uses only the ten approved IO methods. It receives no DOM, storage,
server, browser handle or semantic bridge. Every screenshot has its actual input
call, window, document epoch, PNG length and SHA-256. The harness records scene,
UI and input-consumer observations at that same screenshot call. The oracle
checks the saved bytes against both the capture index and the actual IO receipt.

## Real SH1 lifecycle

The harness gates actual advertisement, lockfile and package HTTP responses.
One lockfile receives appended whitespace while the advertised hash is kept;
both original and served hashes, lengths and corrected headers are retained.
Only already-completed Verify/Joining consumer frames are held for screenshots.
Every hold is released, and fresh documents start with these holds disabled.
SLOT1 clocks never use these SH1 holds.

Connection loss closes both sides of the actual current Joined WebSocket proxy.
The physical driver clicks the product Reload button. The resulting fresh
document must rejoin with the same player and slot. A bounded beforeunload
archive retains the actual old-document click receipts across navigation. The
qualifier requires the real source URL/time origin, exact call and coordinates,
sequence, advancing epoch and distinct fresh-document time origin. Generic
errors and explicit IO reloads cannot use this click-only recovery.

`slot1-authentic-copy-v1` uses three simultaneous windows. A and B join with
separate identities; unclaimed C receives the actual capacity refusal. The
harness then closes C and opens an ordinary child of A without `noopener`.
Actual browser sessionStorage copying, not a JSON reseed, supplies the copied
identity. The retained receipts bind both handle3 document epochs separately.
A/B keep real advancing frames throughout the full copied-window countdown.
The copied page's actual final notice must have distributed glyph pixels after
the focus dimmer is removed by a physical click.

After the copy closes, original A physically reloads within5seconds and rejoins
within15seconds with the same identity and slot. The server's private sibling of
`--stats PATH` records Hello decisions, exact entity generations, connection
epochs, owner history and authority removal, with lossless decimal IDs and
process/wall clocks. It is mode0600 and outside served trees. Authority removal
is not a WebSocket transport-close observation. Keep transport-close timing
NOT TRACED unless an actual matching server event proves it.

## Persistence and native reference

PER1 and `PER1-binding-corruption-proposal.json` are executable settings and
binding corruption cases. A one-use initializer seeds only the exact declared
private fixture before product boot. It retains set/readback values, hashes,
origin, URL, time origin and clocks. A read-only Storage audit calls the original
method and records successful product operations separately from fixture seeds.
The driver receives no storage interface. Both cases require real defaults,
one deduplicated notice, actual namespace/isolation/pruning outcomes and
contrasting notice pixels. The older proposal filename grants no waiver.

`scripts/per1_native_reference.py` discovers and launches the actual locked
`persist` test executable in the assigned cache. It retains process PID, argv,
binary hashes, output, exit code and source manifests. The native test performs
actual isolated-root settings, binding and group reads/writes and reports all
six path/method/hash rows. The raw record is preserved separately from its audit
transformation. The browser launcher pins all seven capsule files in generated
parameters; the public oracle rechecks bytes and the exact transformation.
Caller-supplied reference paths or schema-shaped records cannot qualify it.

Native persistence tests use unique temporary roots and explicit config-root
arguments. They do not mutate process-global HOME or XDG_CONFIG_HOME. Settings
share the existing audio document, preserve unknown fields and untouched audio,
and persist UI/input preferences. Binding keys use the verified mod ID and
compatibility line; group keys also use the actual match ID. Joining prunes old
match groups. Malformed values yield defaults and one notice. An actual runtime
panic from malformed settings must be proved by a valid preboot fixture and a
source-specific WASM panic/page-error record; a startup timeout or missing bridge
alone is setup failure and gives no fault-test credit.

Acceptance results, red/green receipts, source hashes, rulings and fault cycles
are recorded on the MC execution board and in the vault work log. Executable
plans and source contracts alone do not mean Task16 is accepted.
