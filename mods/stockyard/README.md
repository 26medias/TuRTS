# Stockyard public bot fixture

This game uses physical timber inventories. It has no currency cost.
A Timber yard builds sites. A Barracks trains villagers and soldiers.
Both receive harvested timber with the ordinary Store rule.
Both start with 500 timber. Production and construction charge over time.
The castle is only a victory anchor. It cannot build or train units.
The public profile uses the same four stock factories as Skirmish.
The bot can start without a connected human.
Art and its license files are copied unchanged from the Skirmish package.
