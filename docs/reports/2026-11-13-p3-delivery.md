## Review and contract corrections

One independent reviewer runs code for this spec.
The reviewer found ignored decal delays, line offsets, and additive model materials.
Those findings are fixed.
The common-parameter finding also covers line/decal color and size transitions and blending.
Those paths now have tests that inspect actual meshes, transforms, and materials.
A full Low pool retains an opaque plain bolt even when its authored trail is delayed or transparent.

The required temporary faults each made their named row fail.
The restored health, pool, and warning tests passed.
Evidence: `target/mc-evidence/p3-independent-review/`.

Spec corrections:

- Decals may last 120 seconds. The general 10-second limit conflicted with the required 60-second scorch mark.
- Projectile delay must be zero. A delayed projectile would conflict with the required start at Fired.
- `hit_reduced` remains reserved. The wire has no reduction fact, and skirmish has no reduction mechanic.
- No minimap is present, so the conditional minimap warning does not apply.
- A fresh terminal snapshot may show death pictures for known actors removed by that snapshot. The server sends no final shot/destruction facts. This exception requires a coherent prior tick within four ticks. It never invents a shot or replays old deaths. Defeat alone is not a terminal match.
