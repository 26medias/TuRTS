# Player-side inventory: what an RTS player does, sees, and needs

Author seat: player. Mode: review-spec (outside yardstick).
Part A was written first, from play memory, before any repo file was opened.
Part A facts come from play memory. They are NOT TRACED against game files or manuals.
Hotkeys are the default grid or classic layout. Some games let the player change them.

# Part A1. The first ten minutes, game by game

## StarCraft 2 (1v1 ladder, Terran)

1. The loading screen ends. I see my Command Center, 12 SCVs, and 8 mineral patches and 2 gas geysers.
2. The SCVs already mine on their own at match start (since LotV). I see them move from minerals to the Command Center.
3. I read the top-right resource bar: minerals 50, gas 0, supply 12/15.
4. I read the bottom-left minimap. I see my start location as a coloured blob. Fog covers the rest. On a 2-player map I know where the enemy is.
5. I left-click the Command Center. A selection circle appears around it. The bottom panel shows the portrait, the name, the health, and the command card (grid of buttons).
6. I press S (build SCV). I hear a click. A queue slot fills. A progress bar runs in the panel.
7. I shift-press S again to queue more. I see up to 5 icons in the queue.
8. I right-click the mineral field with the Command Center selected. A green rally flag appears on the minerals. New SCVs go there and mine on their own.
9. I press F2 or click the idle-worker... (SC2 has an idle worker button at bottom left of the screen). It shows a count. Click selects the idle SCV.
10. I select one SCV with a left-click. I hear "SCV good to go, sir" or a short voice reply.
11. I press B then S (build, supply depot). A green ghost of the depot follows the mouse. It turns red where I cannot place it (on minerals, on a ramp edge, on a unit... units move away).
12. I left-click to place. The SCV walks there. A ghost stays at the spot until the SCV arrives. Minerals drop by 100 only when the build starts.
13. I shift-right-click minerals so the SCV returns to mining after the build (shift queue).
14. At supply 15/15, a voice says "Additional supply depots required" and the supply text turns red. The Build SCV button still works but the order fails with a text message in the middle of the screen: "Not enough supply".
15. I press B then R (refinery) on a geyser. Then I select 3 SCVs by drag-box (left-drag a rectangle) and right-click the refinery.
16. I build a Barracks (B, B). The build takes time. A progress bar shows on the building and in the panel.
17. I press Ctrl+1 with the Command Center selected to set control group 1. A small number tab appears above the panel.
18. I press 1 to select it again. I press 1 twice to centre the camera on it.
19. I set the Barracks to group 2 or I add it to group 1 with Shift+1 (in some setups I use Ctrl+Shift).
20. I move the camera with the mouse at the screen edge, with the arrow keys, or by left-click on the minimap. I can also middle-drag to pan.
21. I save camera spots with Ctrl+F5 and recall them with F5 (default in some layouts).
22. I send one SCV to scout: right-click on the minimap at the enemy base. It walks there. The fog lifts around it as it walks.
23. At the enemy base I see their buildings. When it leaves, those buildings stay as a grey snapshot in the fog (last seen).
24. I build a Marine (A in the Barracks card). On complete, I hear "You want a piece of me, boy?".
25. I set the Barracks rally point with right-click on the ground. A flag and a line show where new units go.
26. I select all army by F2 (select all army hotkey) or by drag-box.
27. I press A then left-click on the ground (attack-move). Units walk and stop to shoot at anything hostile on the way.
28. I right-click an enemy unit (direct attack). Units chase and shoot that one target.
29. I press S (stop) and H (hold position).
30. In a fight, I see health bars above damaged units (or all units when I hold Alt). Green turns yellow then red.
31. I hear "Your base is under attack" and a red ping flashes on the minimap. I press Space (or Backspace in old versions) to jump the camera to the last alert.
32. I double-click a Marine to select all Marines on screen. I Ctrl+click to do the same.
33. With many units selected, the panel shows a grid of unit wireframes. I click one to select only it. I Shift-click to remove it from the selection.
34. I press Tab to cycle the sub-group (for example Marines then Marauders) in a mixed selection so the command card shows the right abilities.
35. I hover a button. A tooltip shows the name, the cost (minerals, gas, supply), the build time, the hotkey, and a short text.
36. If I cannot afford it, a voice says "Not enough minerals" and a text appears.
37. I research Stimpack in a Tech Lab. The progress shows in the building panel.
38. I use an ability (T for Stim). I see a visual change and the health bar drops.
39. Units collide softly and form a ball. They walk around buildings and up ramps.
40. I check the top bar for the game clock and the APM (if turned on). I can press F10 for the menu, and type gg to surrender. A victory or defeat screen ends the match with a score screen.

## Command & Conquer: Red Alert 2 (skirmish, Allies)

1. I start with an MCV (mobile construction vehicle) and a few infantry. Some modes give a Construction Yard at start.
2. I select the MCV with a left-click. I hear a voice line.
3. I double-click it (or click it and press the deploy key D) to deploy. It unfolds into a Construction Yard. A deploy animation plays.
4. I read the sidebar on the right. It has the radar (minimap) at the top, the money counter, the power bar, and tabs: buildings, defences, infantry, vehicles.
5. The radar is dark until I build a Radar building (Air Force Command). With no radar, the minimap shows nothing.
6. I left-click the Power Plant icon on the sidebar. The icon shows a clock wipe as it builds. Money counts down as it builds, not all at once.
7. When it finishes, a voice says "Construction complete". The icon flashes "Ready".
8. I click the ready icon. A placement grid follows the mouse. Green cells are good. Red cells are blocked. I must place near my existing buildings (build radius).
9. I left-click to place. The building appears with a build-up animation.
10. I build an Ore Refinery. It comes with a free Chrono Miner (harvester). The miner drives to the nearest ore field on its own.
11. I watch the miner fill. It returns to the refinery and unloads. The money counter ticks up with a coin sound.
12. I read the power bar on the sidebar. It goes from green to yellow to red when use is above output.
13. When power is low, a voice says "Low power". Production slows. The radar goes off. Defences stop.
14. I build Barracks. The infantry tab lights up.
15. I left-click the GI icon. I right-click the icon to cancel or put on hold. I click several times to queue; a number shows on the icon.
16. I set a rally point: select the Barracks and click the ground. A flag shows.
17. I drag-box over units to select. Selected units show a health bar ("pip bar") and a selection box.
18. I left-click on the ground to move (classic RA2 left-click control). I left-click an enemy to attack.
19. I press Ctrl+1 to make team 1 and 1 to select it. Double-tap 1 centres on it.
20. I press Ctrl + left-click to force-fire on the ground or a friendly target.
21. I press Ctrl+Shift to attack-move in some versions; or I use the guard command (G) so units guard an area.
22. I press S to stop. I press X to scatter.
23. I press T to select all units of the same type on screen; T twice for the whole map.
24. I press P to select all units (in some setups) or Q... (the exact key is NOT TRACED).
25. I use the waypoint mode (Z) to set a path of waypoints with clicks. Units follow it.
26. I scroll with the mouse at the screen edge, or right-drag to pan. I click the radar to jump.
27. I hear "Unit lost" when a unit dies. I hear "Our base is under attack" with a radar flash.
28. I build a War Factory. I build Grizzly tanks. I hear the unit voice on each order ("Grizzly tank, ready").
29. Veterancy: a unit with many kills gets a chevron. I see the icon on its health bar.
30. I sell a building (dollar sign button on the sidebar top, then click a building). I get money back.
31. I repair a building (wrench button, then click a building). The money drops as it repairs.
32. I build a Pillbox and a Prism Tower to defend. They shoot on their own when enemies come in range.
33. I see the shroud: black until explored. Once explored, it stays revealed in classic RA2 (no fog of war return by default).
34. An Engineer can capture an enemy building: left-click the building with the Engineer selected; the cursor changes to show it.
35. The cursor changes per target: move, attack (crosshair), no-go (crossed circle), enter, capture, deploy.
36. Superweapons show a countdown timer on screen for all players.
37. I win when all enemy buildings and units (or all buildings, per mode) are gone. A "Mission accomplished" text and voice play.

## Age of Empires 2 (Definitive Edition, random map 1v1)

1. I start with a Town Center, 3 villagers, 1 scout cavalry, and 200 food, 200 wood, 100 gold, 200 stone.
2. I read the top-left resource bar: wood, food, gold, stone, population (4/5), and the age.
3. I press H to select the Town Center. I press Q to train a villager. I hear a short sound.
4. I shift-click to queue 5 villagers.
5. I set the Town Center gather point with right-click on a sheep or on the berry bush.
6. I select villagers with drag-box. I press Shift+drag to add to the selection.
7. I press the build key then the House key (Q, Q in grid hotkeys; or B then E in classic). A ghost of the house follows the mouse. Red ghost means I cannot place.
8. I shift-place two houses in a row. Two villagers build them one after the other.
9. I read the population counter. At max, the text flashes red and a sound plays.
10. I send the scout: select it, right-click far away. The fog lifts around it. The explored area stays visible but grey (fog of war). Units in grey area are hidden.
11. The scout finds sheep. I right-click to take them. They become my colour.
12. I select the idle-villager button (bottom-left, "." key). It cycles through idle villagers. A number shows how many are idle.
13. I right-click a sheep with villagers. They kill it and gather food. Food carry count shows above the villager in the panel.
14. I build a Lumber Camp next to trees. I right-click trees. Villagers chop and walk to the camp to drop off.
15. I build a Mill next to berries.
16. The Town Center can shoot arrows if villagers garrison (Alt+G or the town bell).
17. I ring the Town Bell (button on the Town Center) when attacked. All villagers run inside.
18. I read the score/timer at top right. I see the game time.
19. I build a Barracks. I train Militia. I set its gather point.
20. I press Ctrl+1 to make group 1. I press 1 to select. I press 1 twice to centre.
21. I choose a formation (line, box, staggered, flank) on the command panel.
22. I choose a stance (aggressive, defensive, stand ground, no attack).
23. I press A... (attack-move exists in DE via a key; older versions had none). Older AoE2 had only right-click attack and "attack-move" by patrol.
24. I use Patrol (Z) between two points.
25. I hear "Wololo"... no, that is the monk. I hear villager voice clicks in my civ language on each order.
26. I research Loom at the Town Center. I click Feudal Age. A progress bar runs. A horn plays for all players when someone advances.
27. I read the tooltip on hover: cost, time, what it does, what it counters.
28. I see the tech tree screen (F2 or a button): all units and techs for my civ.
29. The minimap shows my units as dots in my colour, resources as coloured dots (gold, stone, trees). I click a minimap mode button to change its view.
30. I hear "a sound and see a flash on the minimap" when a villager is attacked. I press Home to jump to the alert.
31. I see villagers' carry counts and the economy panel in DE (F4 or overlay).
32. I see health bars above units when selected, and above damaged units with an option.
33. I build a Palisade wall by drag: click the start and drag to the end. A line of ghost segments shows.
34. I delete a unit or building with Delete. A confirm may appear.
35. Double-click a unit to select all of that type on screen.
36. Ctrl+click on the idle villager button or Ctrl+... selects all of a type (NOT TRACED).
37. I see the in-game chat and taunts (numbers like 11 for laugh).
38. I win by conquest (destroy all units and buildings that count), wonder, or relics. The other player can resign. A score screen shows graphs.

## Warcraft 3 (Reforged, 1v1, Human)

1. I start with a Town Hall, 5 Peasants, and a gold mine with Peasants already mining. In Melee, the hero altar is not yet built.
2. I read the top-right bar: gold 500, lumber 150, food 5/12, and the upkeep text (No Upkeep / Low / High).
3. I read the day/night clock at the top middle. Night shrinks sight.
4. I select the Town Hall. I press P to train a Peasant. A queue of up to 7 shows.
5. I set the rally point with right-click on the gold mine. New peasants mine on their own.
6. I send 1 Peasant to build an Altar of Kings: B, then A. A ghost shows. Green grid cells are good. Red cells block.
7. I build a Farm (supply) and a Barracks.
8. I select peasants and right-click trees for lumber.
9. I press the idle worker button (bottom-left icon, F8). It cycles idle peasants.
10. I build the hero from the Altar. A hero icon appears at the top-left of the screen. I can press F1 to select the hero.
11. The hero has a level, XP bar, 6 inventory slots, and skill points. I press O (learn skill) and pick a skill.
12. I creep: I send the hero and units to neutral creep camps (shown as coloured dots on the minimap: green, orange, red by difficulty).
13. I attack-move (A + left-click). Units fight creeps. Creeps drop items.
14. I pick up items: right-click the item on the ground. It goes into the hero inventory. I use it with numpad keys or a click.
15. Damage numbers float. Gold coin text "+15" floats on creep kills.
16. I read the unit info panel: attack type, armour type, damage, armour value, speed. I hover for a tooltip on what the types mean.
17. I set control groups Ctrl+1, Ctrl+2. I press Tab to switch the active sub-group so the command card shows its spells.
18. I cast spells with a hotkey then a left-click on the target. A targeting cursor and an area circle show.
19. Autocast: right-click a spell icon to toggle autocast. A golden ring spins on the icon.
20. I hear unit voice lines on select and on order. Clicking a unit many times plays a joke line.
21. I hear "Our town is under attack". A minimap ping flashes. Space jumps to it.
22. I see health and mana bars over units. I press [ or ] to show all bars, or Alt.
23. I use the Town Hall's "Call to Arms": peasants turn into militia for 45 seconds.
24. I see the fog of war: black (unexplored), grey (explored, not seen), clear (seen). Trees block sight on high ground. Low ground cannot see high ground.
25. I scout with a Peasant or a hero.
26. I see the shop (neutral building) and the tavern. I buy with right-click.
27. I see upkeep: when food goes above 50, gold income drops. The upkeep text turns yellow.
28. I see the score screen at end. The match ends when all buildings of one side are gone (or reveal after a timer when a player has no town hall).
29. I can type in chat with Enter. I can ping the minimap with Alt+click for allies.
30. I see selection circles in team colour under units, green for mine, yellow for allied, red for enemy (option).
31. I right-click to move. I hold Shift to queue orders. Waypoint flags show.
32. I press H to hold position. I press S to stop. I press P to patrol.
33. I hear "Not enough gold" and see red text.
34. I can see the enemy hero level icons in the scoreboard? No. I see the enemy hero only when it is in sight. I see an ally's hero portraits.
35. Buildings show a construction progress bar. The peasant animates hammering.

## Supreme Commander (Forged Alliance, 1v1)

1. I start with one Armoured Command Unit (ACU). It warps in with an animation. If it dies, I lose (assassination mode, the usual default).
2. I read the top resource bar: mass and energy. Each shows stored, max storage, income per second (green), and use per second (red).
3. I select the ACU. The build menu at the bottom shows tabs: factories, economy, defence, intel.
4. I build mass extractors on mass points. Mass points show as symbols on the ground and the minimap.
5. I place a build queue with Shift: the ACU will build in order. Ghost outlines show each planned building. Lines join them.
6. I build power generators next to each other. Adjacency bonus shows when buildings touch.
7. I build a Land Factory. I set it to repeat build (infinite loop toggle).
8. I queue engineers. I set the factory rally point.
9. I zoom out with the mouse wheel. At full zoom-out, units turn into strategic icons (shapes by role: square factory, triangle tank, etc.). The map is the minimap.
10. I zoom in on the cursor. The camera moves smoothly.
11. I split the screen into two views (in FA, a dual-monitor option and split view).
12. I drag-box to select. I double-click to select all of that type on screen.
13. I right-click to move. I hold Shift and right-click to queue waypoints. Lines and markers show the path plan.
14. I attack-move (A + click), patrol, and use formation move: right-drag to set a facing and spread of a formation.
15. I order engineers to assist a factory (right-click the factory). They speed it up.
16. I order engineers to reclaim wrecks and trees. Mass flows into my bar. A small number appears.
17. When energy use is above income and storage is empty, the bar flashes. Production stalls (economy stall). The game slows everything that uses energy.
18. I hear "Base under attack" or "Commander under attack" and see a ping.
19. I see radar coverage as a circle. Units in radar show as blips (unknown type) until seen.
20. I build a radar tower to see far. Units in radar but not in sight show as icons.
21. I use control groups Ctrl+1 to Ctrl+0.
22. I use templates: I record a group of buildings and place it again.
23. I read the units' veterancy stars.
24. I read the score, the timer, and the unit count at top.
25. I see the unit cap (for example 500 or 1000). The counter shows in the top bar.
26. I build T1 point defence. It shoots on its own.
27. I set unit fire state: return fire, hold fire, fire at will.
28. I set a ferry route for air transports.
29. Shells fly in visible arcs. Units take damage as projectiles hit, not instantly. Missed shots land on the ground.
30. Wrecks remain after units die. They hold mass.
31. I see the ACU health bar and portrait always in the top-left (or I keep it on a control group).
32. I check a scoreboard on the right side that shows each player's name and score (and mass in teams).
33. I see the terrain height: hills block line of sight and direct fire.
34. I see "Unable to build: insufficient mass" style messages? (Mostly the build is slowed, not refused. Resources are taken over time.)
35. The game ends when an ACU dies; the ACU explodes in a big nuclear blast.

## Factorio (freeplay, first ten minutes)

Factorio is not a classic RTS. It has one avatar, no armies, no selection box of units. I include it as the factory/logistics yardstick.

1. I land at a crash site. I control one character with W, A, S, D.
2. I see the toolbar (quickbar) at the bottom with 10 slots per row, a health bar, and the minimap at top right.
3. I hold the right mouse button on a rock or tree to mine it by hand. A progress bar fills under the cursor.
4. I open the inventory with E. I see the crafting grid on the right. I left-click an item to hand-craft. A queue shows at the bottom left.
5. I hover any item. A tooltip shows the recipe, the time, and the ingredients.
6. I pick a Burner Mining Drill from the inventory. A ghost follows the cursor. It shows the mining area. It turns red where blocked.
7. I press R to rotate the ghost. An arrow shows the output side.
8. I left-click to place it on iron ore. I see a red flashing "no fuel" icon on it.
9. I put coal into it: Ctrl+click on the drill puts fuel from my inventory, or I open it and drag coal in.
10. I place a Stone Furnace at the drill output. The drill drops ore into the furnace.
11. I open the furnace (left-click) and see the input, fuel, and output slots and a progress bar.
12. I see an alt-mode overlay (Alt) that shows icons of the recipe and contents above each machine.
13. I drag a transport belt line with left-click held. Belts follow the mouse. Arrows show direction.
14. I place inserters. They swing items from belt to machine. Their reach shows as a highlight when I hold one.
15. I pipette (Q) a building to put the same item in my hand.
16. I copy settings with Shift+right-click and paste with Shift+left-click.
17. I pick up a building with right-click held (mining it back). The items go to my inventory.
18. I research a technology: T opens the tech tree. I pick red science. A bar at the top right shows research progress.
19. I build labs and fill them with science packs. The labs animate.
20. I see the "shortcut bar" alerts at bottom right: no fuel, output full, no power, under attack, structure destroyed. Each alert has an icon and I can click to see it on the map.
21. I open the map with M. I see explored chunks, pollution cloud (option), and enemy nests (red).
22. I see power: steam engines need a boiler and offshore pump. Hover a pole: the power graph shows production versus use. A yellow "low power" icon flashes on machines.
23. I see pollution spread on the map. Biters attack when pollution reaches their nests.
24. I build turrets and fill them with ammo. Turrets shoot biters on their own.
25. I lose if my character dies? No: I respawn. There is no win in the first ten minutes. The goal is to launch a rocket (long term).
26. I use blueprints later (B or the blueprint tool): drag a box to copy a set of buildings.
27. I use the deconstruction planner: drag a box to mark buildings for removal.
28. I can zoom with the mouse wheel. Far zoom shows the map view.
29. I see the item count on the cursor stack and in the quickbar.
30. I see sounds per machine: drills, furnaces, inserters. A sound confirms placement.

# Part A2. What makes it an RTS

Each item: what it is, why a player calls the game broken without it, CORE (every classic RTS has it; I stop playing without it) or COMMON (most have it; I miss it).

1. Click-select one unit or building. CORE. Without it I control nothing.
2. Box-select (left-drag a rectangle) to select many units. CORE. Armies of 20 units cannot be clicked one by one.
3. Shift-click / Shift-drag to add or remove units in a selection. CORE. I must fix a selection without starting again.
4. Select all of one type (double-click or Ctrl+click). COMMON. Splitting an army by type is basic control.
5. Right-click (or context click) to give the natural order: move on ground, attack on enemy, gather on resource, repair on damaged friendly. CORE. One click per order is the language of the genre.
6. Group order: one order moves all selected units. CORE. Without it each unit needs its own order.
7. Group movement that keeps units together and does not stack them on one pixel. CORE. Units in one clump that block each other look broken.
8. Attack-move. CORE (since StarCraft). Without it, units walk past enemies while being shot.
9. Stop and hold position. CORE. I must cancel an order and keep units from chasing.
10. Order queue with Shift (waypoints, build queue for a worker). COMMON (CORE for SupCom). Planning ahead is a skill layer.
11. Control groups (Ctrl+number to set, number to recall, double-tap to centre). CORE. With more than one army or base, no control groups means no play.
12. Hotkeys for commands and for production. CORE for competitive play; COMMON for casual. Clicking every button is too slow.
13. Visible selection feedback: circle or box under selected units, team colour. CORE. I must see what I have selected.
14. Selection panel: portrait or icon grid, name, health, what it does. CORE. I must see what a unit is and what it can do.
15. Command card or build menu: buttons for orders and things to build, with cost. CORE. Without it I cannot build.
16. Tooltip on hover with cost, time, and short text. CORE. Without it I cannot learn what a button does.
17. Refused-order feedback: "Not enough money", "Cannot build there", a red ghost, a voice line. CORE. A silent refusal feels like a bug.
18. Placement ghost (green or red) when I place a building. CORE. I must see where it goes before I pay.
19. Production queue and progress bar. CORE. I must see what is being made and how long it takes.
20. Rally point with a visible flag. CORE. Every new unit must go where I want without a click each.
21. Resource bar always on screen (money, power or supply). CORE. I must know what I can afford.
22. Supply or population cap, shown. COMMON. A limit on army size; I must see it before I hit it.
23. Power shown, low-power warning. COMMON (CORE for the TuRTS first mod by its rules). I must know why things slowed.
24. Minimap with my units, enemy units in sight, and click-to-jump. CORE. I cannot find the fight without it.
25. Camera pan (screen edge, keys, middle drag) and zoom. CORE. I must look around the map.
26. Fog of war: unexplored black, explored grey, seen clear. CORE. Scouting and surprise come from it.
27. Last-seen building snapshot in the fog. COMMON. I must remember where the enemy base is.
28. Health bars over units (on select, on damage, or on Alt). CORE. I must see who is losing a fight.
29. Alerts: "Base under attack", "Unit lost", with a minimap ping and a jump key. CORE. I cannot watch every place at once.
30. Unit voice or sound on select and on order. COMMON. It confirms the click took. Silence feels like lag.
31. Visible attack: projectile or muzzle flash, hit effect, death effect. CORE. A fight must look like a fight.
32. Units auto-acquire targets in range. CORE. Units that stand still while shot feel broken.
33. Workers that gather and return on their own. CORE. An economy that needs a click per trip is not an RTS economy.
34. Idle-worker button or alert. COMMON. Idle workers waste money with no sign.
35. Cursor that changes per target (move, attack, cannot). COMMON. It tells me what my click will do.
36. Win and lose screen with the reason. CORE. A match must end, and I must know why.
37. Cancel build or production and get money back. COMMON. Mistakes must be fixable.
38. Pause or menu, surrender. COMMON. I must leave a match cleanly.

## Factorio note

For Factorio the core list is different: avatar move (WASD), hand mining, hand crafting, inventory, placement ghost with rotate, belts and inserters, power network with a graph, research, alerts for machine problems, and copy-paste of settings or blueprints. Box-select and control groups do not apply. Blueprint box-select and the deconstruction box do apply (a drag rectangle).

# Part A3. What a modder changes

Facts are from modding memory. NOT TRACED against the tools.

1. Hotkeys (item 12). SC2: the hotkey file (.SC2Hotkeys) and the button data in the Galaxy Editor data editor (Button, "Hotkey" field). RA2: the game strings (ra2md.csf) carry the &-marked keys; keyboard.ini holds the player layout. AoE2 DE: the hotkey profile file (.hkp) and the in-game editor. WC3: CustomKeys.txt (button hotkeys and positions). SupCom: a Lua key map file (keymap / Lua key actions). Factorio: the mod's data.lua declares custom-input prototypes with a key sequence.
2. Command card layout (item 15). SC2: the Command Card in the unit's data (button, row, column). RA2: the sidebar is fixed; the mod edits rulesmd.ini (Prerequisite, Owner, TechLevel) to change which buttons appear. AoE2: data file (.dat) button position fields. WC3: the object editor (Button position X/Y) and CustomKeys.txt. SupCom: the unit blueprint (.bp, Lua) fields BuildableCategory and the Lua UI layout files. Factorio: crafting-menu categories and subgroups in prototypes.
3. Unit costs and build time (items 15, 19). SC2: data editor, unit Cost and Build Time. RA2: rulesmd.ini Cost= and the build speed setting. AoE2: the .dat file via the scenario editor or AGE tool. WC3: object editor gold, lumber, build time. SupCom: unit blueprint Economy block (BuildCostMass, BuildCostEnergy, BuildTime). Factorio: recipe prototype (ingredients, energy_required).
4. Selection behaviour (items 1 to 4). SC2: data flags (Unselectable, "Prevent Defeat", selection priority, sub-group priority). RA2: rulesmd.ini Selectable=, and the YR "Insignificant" style flags. AoE2: limited; .dat interface kind. WC3: unit flags in the object editor; selection scale and priority fields. SupCom: Lua UI scripts can change selection filters; SelectionPriority in the blueprint. Factorio: selection box and selection priority on each prototype.
